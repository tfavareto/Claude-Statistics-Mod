# Security policy

## Supported versions

The latest release on `main` is supported.

## Scope

The three mods in `plugins/`: what they read, what they call, and anything that could expose a user's data or act
without their consent. See [docs/03-privacy-and-security.md](docs/03-privacy-and-security.md) for what each mod
reads and calls.

## Report a vulnerability

Report privately through GitHub's advisory form:
<https://github.com/tfavareto/claude-desktop-mods/security/advisories/new>.

Include the mod and version, the steps to reproduce, what you expected and what happened. Do not include tokens,
account ids or private content. You will get a first answer within a week.

## Out of scope

Bugs in the Claude desktop app or the Claude Code engine itself: report those to Anthropic.
